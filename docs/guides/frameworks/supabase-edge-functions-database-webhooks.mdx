A Supabase database webhook posts each new row to a [hosted webhook endpoint](/webhooks/overview), and Trigger.dev runs a task with the row. You don't need an Edge Function.

In this guide:

- A Supabase database webhook fires when a row with a video URL is inserted into a table
- Trigger.dev checks the webhook's shared secret and runs the `transcribe-video` task with the row
- The task transcribes the video with [Deepgram](https://deepgram.com) and writes the transcription back to the same row

## Prerequisites

- A Supabase project
- The [Supabase CLI](https://supabase.com/docs/guides/cli/getting-started), logged in with `supabase login`
- Trigger.dev set up in your project with the [quick start](/quick-start) (`npx trigger.dev@latest init`), using `@trigger.dev/sdk` 4.8.1 or later. See [Webhooks public beta](/webhooks/public-beta#install-the-packages)
- A [Deepgram](https://deepgram.com) API key

## Create the table

In the Supabase dashboard, open the **Table Editor** <Icon icon="circle-1" iconType="solid" size={20} color="A8FF53" /> and create a new table <Icon icon="circle-2" iconType="solid" size={20} color="A8FF53" />.

![How to create a new Supabase table](/images/supabase-new-table-1.png)

Call the table `video_transcriptions` <Icon icon="circle-1" iconType="solid" size={20} color="A8FF53" />. Add a `video_url` column of type `text` <Icon icon="circle-2" iconType="solid" size={20} color="A8FF53" /> and a `transcription` column of type `text` <Icon icon="circle-3" iconType="solid" size={20} color="A8FF53" />.

![How to create a new Supabase table 2](/images/supabase-new-table-2.png)

## Generate the database types

Generate [type definitions](https://supabase.com/docs/guides/api/rest/generating-types) for your schema so the task's database calls are typed. Run this in the root of your project:

```bash
supabase gen types --lang=typescript --remote=<project-ref> --schema public > database.types.ts
```

Replace `<project-ref>` with your project's reference ID, which is in the project's URL in the dashboard.

## Write the task

Install the Deepgram and Supabase clients:

<CodeGroup>

```bash npm
npm i @deepgram/sdk @supabase/supabase-js
```

```bash pnpm
pnpm add @deepgram/sdk @supabase/supabase-js
```

```bash bun
bun add @deepgram/sdk @supabase/supabase-js
```

</CodeGroup>

Create the endpoint and the task. The endpoint uses `webhooks.supabase()`, and the filter means only inserts into `video_transcriptions` start a run:

```ts src/trigger/transcribe-video.ts
import { DeepgramClient } from "@deepgram/sdk";
import { createClient } from "@supabase/supabase-js";
import { logger, webhook, webhooks } from "@trigger.dev/sdk";
import type { Database } from "../../database.types"; // the file generated in the previous step

type VideoTranscription = Database["public"]["Tables"]["video_transcriptions"]["Row"];

// The bodies a Supabase database webhook sends
type DatabaseWebhookEvent =
  | { type: "INSERT"; table: string; schema: string; record: VideoTranscription; old_record: null }
  | { type: "UPDATE"; table: string; schema: string; record: VideoTranscription; old_record: VideoTranscription }
  | { type: "DELETE"; table: string; schema: string; record: null; old_record: VideoTranscription };

export const supabaseDatabase = webhooks.endpoint.define({
  id: "supabase-database",
  source: webhooks.supabase<DatabaseWebhookEvent>(),
});

export const transcribeVideo = webhook({
  id: "transcribe-video",
  endpoint: supabaseDatabase,
  filter: "event.type == 'INSERT' && event.table == 'video_transcriptions'",
  onEvent: async ({ event }) => {
    const { id, video_url: videoUrl } = event.record; // the filter narrows event to an INSERT

    if (!videoUrl) {
      logger.warn("Row has no video_url", { id });
      return;
    }

    // Create the clients here, not when the file loads, so a missing variable only fails this run
    const deepgram = new DeepgramClient({ apiKey: process.env.DEEPGRAM_API_KEY });
    const supabase = createClient<Database>(
      process.env.SUPABASE_URL as string,
      process.env.SUPABASE_SECRET_KEY as string // server-side secret key
    );

    // Deepgram fetches the video and transcribes its audio track
    const response = await deepgram.listen.v1.media.transcribeUrl({
      url: videoUrl,
      model: "nova-3",
      smart_format: true,
    });

    if (!("results" in response)) {
      throw new Error(`Deepgram returned no results for row ${id}`);
    }

    const transcription =
      response.results.channels[0]?.alternatives?.[0]?.paragraphs?.transcript ?? null;

    logger.log("Transcription", { id, transcription });

    const { error } = await supabase
      .from("video_transcriptions")
      .update({ transcription })
      .eq("id", id);

    if (error) {
      throw new Error(`Failed to update row ${id}: ${error.message}`);
    }
  },
});
```

Put the file in a folder listed in `dirs` in your `trigger.config.ts`. The import path assumes that folder is `src/trigger` and `database.types.ts` is in the project root. Adjust it if your layout differs.

<Warning>
  A task that a database change triggers can trigger itself again if it writes to the same table.
  Here the webhook only fires on `INSERT` and the task only runs `update`, so it can't loop.
</Warning>

The secret key bypasses Row Level Security. Use it only in server-side code such as tasks. See the [Supabase authentication guide](/guides/frameworks/supabase-authentication) for user-scoped access.

## Add the environment variables

On the **Environment variables** page of your Trigger.dev project, add these to the Production environment. To run the task with `trigger dev`, add them to the Development environment too.

| Variable | Value |
| --- | --- |
| `SUPABASE_URL` | Your project URL, from the **Connect** dialog in the Supabase dashboard |
| `SUPABASE_SECRET_KEY` | A secret key (`sb_secret_...`) from **Settings > API Keys** in the Supabase dashboard. Create one if the project has none. |
| `DEEPGRAM_API_KEY` | Your Deepgram API key |

## Connect the database webhook

Supabase database webhooks aren't signed, so the endpoint checks a shared secret in the `Authorization` header instead.

<Steps>
  <Step title="Generate the endpoint's secret">
    Open the `supabase-database` endpoint on the **Webhooks** page, choose **Generate secret**, then choose **Generate secret** again in the dialog. Copy the value: Trigger.dev shows it only once. Supabase has no signing-secret field, so the secret goes in a header in the next step. Copy the endpoint's **Webhook URL** too.

    Every delivery is rejected until the secret is set.
  </Step>
  <Step title="Create the webhook in Supabase">
    In the Supabase dashboard, open **Integrations > Database Webhooks**. If the **Overview** tab shows **Enable webhooks**, choose it. Then open the **Webhooks** tab and choose **Create webhook**:

    1. Give it a name, such as `transcribe-video`.
    2. Select the `public` `video_transcriptions` table and the **Insert** event.
    3. Under **Type of webhook**, choose **HTTP Request**, with the method `POST` and the endpoint's **Webhook URL**.
    4. Under **HTTP Headers**, add a header named `Authorization` with the value `Bearer <secret>` (capital B, one space), using the secret you generated.
    5. Create the webhook.
  </Step>
</Steps>

## Test it

Open the **Table Editor** <Icon icon="circle-1" iconType="solid" size={20} color="A8FF53" />, select the `video_transcriptions` table <Icon icon="circle-2" iconType="solid" size={20} color="A8FF53" />, and choose **Insert** > **Insert row** <Icon icon="circle-3" iconType="solid" size={20} color="A8FF53" />.

![How to insert a new row 1](/images/supabase-new-table-3.png)

Set `video_url` to a public video URL <Icon icon="circle-1" iconType="solid" size={20} color="A8FF53" />, such as `https://content.trigger.dev/Supabase%20Edge%20Functions%20Quickstart.mp4`, then choose **Save**.

![How to insert a new row 2](/images/supabase-new-table-4.png)

The delivery appears on the `supabase-database` endpoint's **Deliveries** tab, and its detail page links to the `transcribe-video` run it started. When the run completes, the row's `transcription` column holds the transcript.

![Supabase successful table update](/images/supabase-table-result.png)

If no delivery appears, check the webhook URL and the `Authorization` header in Supabase. A delivery marked **Filtered** wasn't an insert into `video_transcriptions`.
