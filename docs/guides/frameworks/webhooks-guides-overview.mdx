**Trigger.dev hosts webhook endpoints for you: register one URL with a provider, and each verified event runs the subscribed tasks whose filters match it.** You don't write a route handler, verify signatures, or call `tasks.trigger()` yourself.

There are two ways to run tasks from webhooks:

- **Hosted webhook endpoints (recommended):** Trigger.dev receives the request, verifies it, records it as a delivery you can inspect and replay, and runs your subscribed tasks.
- **Your own handler:** a route in your app receives the request, verifies it, and triggers a task with `tasks.trigger()`. Use this when the HTTP response has to come from your app, for example to return a result to the caller, or when no [source](/webhooks/sources) can verify the provider's requests.

## Receive webhooks on a hosted endpoint

Declare an endpoint with a [source](/webhooks/sources), then subscribe tasks to it with `webhook()`:

```ts /trigger/stripe.ts
import { webhook, webhooks } from "@trigger.dev/sdk";

export const stripe = webhooks.endpoint.define({
  id: "stripe",
  source: webhooks.stripe(),
});

export const fulfillOrder = webhook({
  id: "fulfill-order",
  endpoint: stripe,
  filter: "event.type == 'checkout.session.completed'",
  onEvent: async ({ event }) => {
    console.log("Fulfilling", event.data.object.id);
  },
});
```

When you deploy or run `trigger dev`, the endpoint appears on the environment's **Webhooks** page with its URL. Register that URL with Stripe and store the signing secret, and each `checkout.session.completed` event runs `fulfill-order`.

Hosted endpoints give you:

- **Verification for 40+ providers**, including Stripe, GitHub, Clerk, Resend, Shopify, Linear, Supabase and Hookdeck, plus `webhooks.custom()` for other HMAC, public-key or shared-secret schemes.
- **Filters per subscriber**, so one endpoint can route checkout events to one task and refunds to another.
- **Deliveries you can inspect and replay**, with the payload, headers and the runs each event started.
- **Waiters**, which pause a run until a matching event arrives, without using compute while it waits.
- **[Agent routing](/webhooks/session-routing)**, which sends events into a `chat.agent` session, including agents that live in Slack and Linear.

Webhooks are in [public beta](/webhooks/public-beta) and need `@trigger.dev/sdk` 4.8.1 or later.
