**`webhooks.intercom()` verifies Intercom's signature on every request, so subscribers only receive genuine Intercom events.**

```ts /trigger/intercom.ts
import { webhook, webhooks } from "@trigger.dev/sdk";

export const intercom = webhooks.endpoint.define({
  id: "intercom",
  source: webhooks.intercom(),
});

export const intercomEvents = webhook({
  id: "intercom-events",
  endpoint: intercom,
  onEvent: async ({ event }) => {
    console.log(event);
  },
});
```

To run a subscriber only for some events, add a [filter](/webhooks/filters) on `event.topic`.

| | |
| --- | --- |
| Source | `webhooks.intercom()` |
| Verification | HMAC-SHA1 in `x-hub-signature` |
| Credential | Signing secret you generate on Trigger.dev, or one issued by Intercom |
| Event type | `event.topic` |
| Intercom docs | [Intercom webhook docs](https://developers.intercom.com/docs/references/webhooks/webhook-models) |

## Set up Intercom

1. Start `trigger dev` or deploy, then copy the endpoint's **Webhook URL** from the **Webhooks** page.
2. Add the webhook URL as a webhook in Intercom and select the events your subscribers need. See Intercom's [webhook docs](https://developers.intercom.com/docs/references/webhooks/webhook-models) for where its webhook settings are.
3. If Intercom shows a signing secret when you create the webhook, copy it and choose **Set signing secret** on the Trigger.dev endpoint. If Intercom asks you for a secret, choose **Generate secret** on the endpoint and paste the value into Intercom.
4. Send a test event from Intercom, or use the endpoint's **Test** tab, and check the endpoint's **Deliveries** tab. See [Verify the connection](/webhooks/connect#verify-the-connection) if nothing arrives.
