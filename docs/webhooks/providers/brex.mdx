**`webhooks.brex()` verifies Brex's signature on every request, so subscribers only receive genuine Brex events.**

```ts /trigger/brex.ts
import { webhook, webhooks } from "@trigger.dev/sdk";

export const brex = webhooks.endpoint.define({
  id: "brex",
  source: webhooks.brex(),
});

export const brexEvents = webhook({
  id: "brex-events",
  endpoint: brex,
  onEvent: async ({ event }) => {
    console.log(event);
  },
});
```

To run a subscriber only for some events, add a [filter](/webhooks/filters) on `event.event_type`.

| | |
| --- | --- |
| Source | `webhooks.brex()` |
| Verification | Svix (`svix-id`, `svix-timestamp`, `svix-signature`) |
| Credential | Signing secret issued by Brex |
| Event type | `event.event_type` |
| Brex docs | [Brex webhook docs](https://developer.brex.com/docs/webhooks/) |

## Set up Brex

1. Start `trigger dev` or deploy, then copy the endpoint's **Webhook URL** from the **Webhooks** page.
2. Add the webhook URL as an endpoint in Brex's webhook settings and subscribe it to the event types your subscribers need.
3. Copy the endpoint's signing secret (it starts with `whsec_`), then choose **Set signing secret** on the Trigger.dev endpoint.
4. Send a test event from Brex, or use the endpoint's **Test** tab, and check the endpoint's **Deliveries** tab. See [Verify the connection](/webhooks/connect#verify-the-connection) if nothing arrives.
