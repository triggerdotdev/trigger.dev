**`webhooks.zendesk()` verifies Zendesk's signature on every request, so subscribers only receive genuine Zendesk events.**

```ts /trigger/zendesk.ts
import { webhook, webhooks } from "@trigger.dev/sdk";

export const zendesk = webhooks.endpoint.define({
  id: "zendesk",
  source: webhooks.zendesk(),
});

export const zendeskEvents = webhook({
  id: "zendesk-events",
  endpoint: zendesk,
  onEvent: async ({ event }) => {
    console.log(event);
  },
});
```

To run a subscriber only for some events, add a [filter](/webhooks/filters) on `event.status`.

| | |
| --- | --- |
| Source | `webhooks.zendesk()` |
| Verification | HMAC-SHA256 in `x-zendesk-webhook-signature` |
| Credential | Signing secret you generate on Trigger.dev, or one issued by Zendesk |
| Event type | `event.status` |
| Zendesk docs | [Zendesk webhook docs](https://developer.zendesk.com/documentation/webhooks/verifying/) |

## Set up Zendesk

1. Start `trigger dev` or deploy, then copy the endpoint's **Webhook URL** from the **Webhooks** page.
2. Add the webhook URL as a webhook in Zendesk and select the events your subscribers need. See Zendesk's [webhook docs](https://developer.zendesk.com/documentation/webhooks/verifying/) for where its webhook settings are.
3. If Zendesk shows a signing secret when you create the webhook, copy it and choose **Set signing secret** on the Trigger.dev endpoint. If Zendesk asks you for a secret, choose **Generate secret** on the endpoint and paste the value into Zendesk.
4. Send a test event from Zendesk, or use the endpoint's **Test** tab, and check the endpoint's **Deliveries** tab. See [Verify the connection](/webhooks/connect#verify-the-connection) if nothing arrives.
