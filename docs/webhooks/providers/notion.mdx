**`webhooks.notion()` verifies the HMAC-SHA256 signature Notion sends in `x-notion-signature` on every request.**

```ts /trigger/notion.ts
import { webhook, webhooks } from "@trigger.dev/sdk";

export const notion = webhooks.endpoint.define({
  id: "notion",
  source: webhooks.notion(),
});

export const notionEvents = webhook({
  id: "notion-events",
  endpoint: notion,
  filter: "event.type == 'page.created'",
  onEvent: async ({ event }) => {
    console.log(event);
  },
});
```

| Setting | Value |
| --- | --- |
| Source | `webhooks.notion()` |
| Verification | HMAC-SHA256 in `x-notion-signature` |
| Credential | Signing secret issued by Notion |
| Event type | `event.type` |
| Notion docs | [Notion webhook docs](https://developers.notion.com/reference/webhooks) |

## Set up Notion

1. Start `trigger dev` or deploy, then copy the endpoint's **Webhook URL** from the **Webhooks** page.
2. Add the webhook URL as a webhook in Notion and select the events your subscribers need. See Notion's [webhook docs](https://developers.notion.com/reference/webhooks) for where its webhook settings are.
3. Copy the signing secret Notion shows for the webhook, then choose **Set signing secret** on the Trigger.dev endpoint.
4. Send a test event from Notion, or use the endpoint's **Test** tab, and check the endpoint's **Deliveries** tab. See [Verify the connection](/webhooks/connect#verify-the-connection) if nothing arrives.
