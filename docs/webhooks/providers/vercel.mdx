**`webhooks.vercel()` verifies the HMAC-SHA1 signature Vercel sends in `x-vercel-signature` on every request.**

```ts /trigger/vercel.ts
import { webhook, webhooks } from "@trigger.dev/sdk";

export const vercel = webhooks.endpoint.define({
  id: "vercel",
  source: webhooks.vercel(),
});

export const vercelEvents = webhook({
  id: "vercel-events",
  endpoint: vercel,
  filter: "event.type == 'deployment.succeeded'",
  onEvent: async ({ event }) => {
    console.log(event);
  },
});
```

| Setting | Value |
| --- | --- |
| Source | `webhooks.vercel()` |
| Verification | HMAC-SHA1 in `x-vercel-signature` |
| Credential | Signing secret issued by Vercel |
| Event type | `event.type` |
| Vercel docs | [Vercel webhook docs](https://vercel.com/docs/webhooks) |

## Set up Vercel

1. Start `trigger dev` or deploy, then copy the endpoint's **Webhook URL** from the **Webhooks** page.
2. In Vercel, open your team's **Settings > Webhooks** (Pro and Enterprise plans) and create a webhook with the webhook URL and the events your subscribers need.
3. Vercel shows the webhook's secret once, in the dialog after the webhook is created. Copy it then, and choose **Set signing secret** on the Trigger.dev endpoint. Webhooks from a Vercel integration are signed with the integration's Client Secret instead.
4. Send a test event from Vercel, or use the endpoint's **Test** tab, and check the endpoint's **Deliveries** tab. See [Verify the connection](/webhooks/connect#verify-the-connection) if nothing arrives.
