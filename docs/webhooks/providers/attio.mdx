**`webhooks.attio()` verifies the HMAC-SHA256 signature Attio sends in `attio-signature` on every request.**

```ts /trigger/attio.ts
import { webhook, webhooks } from "@trigger.dev/sdk";

export const attio = webhooks.endpoint.define({
  id: "attio",
  source: webhooks.attio(),
});

export const attioEvents = webhook({
  id: "attio-events",
  endpoint: attio,
  onEvent: async ({ event }) => {
    console.log(event);
  },
});
```

| Setting | Value |
| --- | --- |
| Source | `webhooks.attio()` |
| Verification | HMAC-SHA256 in `attio-signature` |
| Credential | Signing secret you generate on Trigger.dev, or one issued by Attio |
| Attio docs | [Attio webhook docs](https://docs.attio.com/rest-api/guides/webhooks) |

## Set up Attio

1. Start `trigger dev` or deploy, then copy the endpoint's **Webhook URL** from the **Webhooks** page.
2. Add the webhook URL as a webhook in Attio and select the events your subscribers need. See Attio's [webhook docs](https://docs.attio.com/rest-api/guides/webhooks) for where its webhook settings are.
3. If Attio shows a signing secret when you create the webhook, copy it and choose **Set signing secret** on the Trigger.dev endpoint. If Attio asks you for a secret, choose **Generate secret** on the endpoint and paste the value into Attio.
4. Send a test event from Attio, or use the endpoint's **Test** tab, and check the endpoint's **Deliveries** tab. See [Verify the connection](/webhooks/connect#verify-the-connection) if nothing arrives.
