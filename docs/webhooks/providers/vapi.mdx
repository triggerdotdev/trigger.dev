**`webhooks.vapi()` verifies Vapi's signature on every request, so subscribers only receive genuine Vapi events.**

```ts /trigger/vapi.ts
import { webhook, webhooks } from "@trigger.dev/sdk";

export const vapi = webhooks.endpoint.define({
  id: "vapi",
  source: webhooks.vapi(),
});

export const vapiEvents = webhook({
  id: "vapi-events",
  endpoint: vapi,
  onEvent: async ({ event }) => {
    console.log(event);
  },
});
```

To run a subscriber only for some events, add a [filter](/webhooks/filters) on `event.message.type`.

| | |
| --- | --- |
| Source | `webhooks.vapi()` |
| Verification | HMAC-SHA256 in `x-vapi-signature` |
| Credential | Signing secret you generate on Trigger.dev, or one issued by Vapi |
| Event type | `event.message.type` |
| Vapi docs | [Vapi webhook docs](https://docs.vapi.ai/server-url/server-authentication) |

## Set up Vapi

1. Start `trigger dev` or deploy, then copy the endpoint's **Webhook URL** from the **Webhooks** page.
2. Add the webhook URL as a webhook in Vapi and select the events your subscribers need. See Vapi's [webhook docs](https://docs.vapi.ai/server-url/server-authentication) for where its webhook settings are.
3. If Vapi shows a signing secret when you create the webhook, copy it and choose **Set signing secret** on the Trigger.dev endpoint. If Vapi asks you for a secret, choose **Generate secret** on the endpoint and paste the value into Vapi.
4. Send a test event from Vapi, or use the endpoint's **Test** tab, and check the endpoint's **Deliveries** tab. See [Verify the connection](/webhooks/connect#verify-the-connection) if nothing arrives.
