**`webhooks.composio()` verifies Composio's signature on every request, so subscribers only receive genuine Composio events.**

```ts /trigger/composio.ts
import { webhook, webhooks } from "@trigger.dev/sdk";

export const composio = webhooks.endpoint.define({
  id: "composio",
  source: webhooks.composio(),
});

export const composioEvents = webhook({
  id: "composio-events",
  endpoint: composio,
  onEvent: async ({ event }) => {
    console.log(event);
  },
});
```

To run a subscriber only for some events, add a [filter](/webhooks/filters) on `event.type`.

| | |
| --- | --- |
| Source | `webhooks.composio()` |
| Verification | Standard Webhooks (`webhook-id`, `webhook-timestamp`, `webhook-signature`) |
| Credential | Signing secret issued by Composio |
| Event type | `event.type` |

## Set up Composio

1. Start `trigger dev` or deploy, then copy the endpoint's **Webhook URL** from the **Webhooks** page.
2. Add the webhook URL as an endpoint in Composio's webhook settings and subscribe it to the event types your subscribers need.
3. Copy the endpoint's signing secret (it starts with `whsec_`), then choose **Set signing secret** on the Trigger.dev endpoint.
4. Send a test event from Composio, or use the endpoint's **Test** tab, and check the endpoint's **Deliveries** tab. See [Verify the connection](/webhooks/connect#verify-the-connection) if nothing arrives.
