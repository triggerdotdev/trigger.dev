**`webhooks.stripe()` verifies Stripe's signature on every request, so subscribers only receive genuine Stripe events.**

```ts /trigger/stripe.ts
import { webhook, webhooks } from "@trigger.dev/sdk";

export const stripe = webhooks.endpoint.define({
  id: "stripe",
  source: webhooks.stripe(),
});

export const stripeEvents = webhook({
  id: "stripe-events",
  endpoint: stripe,
  filter: "event.type == 'checkout.session.completed'",
  onEvent: async ({ event }) => {
    console.log(event);
  },
});
```

| | |
| --- | --- |
| Source | `webhooks.stripe()` |
| Verification | HMAC-SHA256 in `stripe-signature`, with a timestamp tolerance |
| Credential | Signing secret issued by Stripe |
| Event type | `event.type` |
| Stripe docs | [Stripe webhook docs](https://docs.stripe.com/webhooks) |

## Set up Stripe

1. Start `trigger dev` or deploy, then copy the endpoint's **Webhook URL** from the **Webhooks** page.
2. Create the webhook endpoint with the Stripe CLI or API, not the Dashboard, so you can read the signing secret from the response:

   ```bash
   stripe webhook_endpoints create -d url="<webhook URL>" -d "enabled_events[]=checkout.session.completed"
   ```

   The response's `secret` field is the signing secret; Stripe only returns it when the endpoint is created.
3. Choose **Set signing secret** on the Trigger.dev endpoint and paste the secret.
4. Use a test mode key for dev and staging environments and a live mode key for production.
5. Send a test event from Stripe, or use the endpoint's **Test** tab, and check the endpoint's **Deliveries** tab. See [Verify the connection](/webhooks/connect#verify-the-connection) if nothing arrives.

## Typing the event

`webhooks.stripe()` provides a default event shape. For the full Stripe types, install the `stripe` package and pass `Stripe.Event`:

```ts /trigger/stripe.ts
import type Stripe from "stripe";
import { webhooks } from "@trigger.dev/sdk";

export const stripe = webhooks.endpoint.define({
  id: "stripe",
  source: webhooks.stripe<Stripe.Event>(),
});
```
