The remote MCP server can now list the tags used on your runs, search and read your logs, add tags, update metadata, reset idempotency keys and reschedule delayed runs, and run details now include the run's metadata values. It can also list, read, create and abort bulk actions that cancel or replay many runs at once, and you approve every bulk action it creates. It can also read what a run streamed. Edits that would change nothing are refused without asking you to approve them.
