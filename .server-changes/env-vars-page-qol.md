Environment variables page: after adding a variable, the list switches to the environment you saved it in and opens the page that holds the new key, with a toast naming where it went. The `env` filter in the URL also accepts `development`, `staging` and `production`. The compare view has a copy button on each key, and each row's edit and delete buttons are named after the key and environment for screen readers.
