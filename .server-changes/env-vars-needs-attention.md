Environment variables page: a new Needs attention page lists the keys in one environment that are empty, missing compared with your other environments, changed in the last day, or replaceable with OIDC, with copy, delete and ignore actions. The OIDC page is now a grid of providers with setup in a side panel, it points at environment variables OIDC could replace, and there are setup guides for Azure, Google Cloud, HashiCorp Vault, Doppler, Snowflake and Databricks.
